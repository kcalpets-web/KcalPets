# แผน: อาวุธธาตุ + ธนูหลายแบบ (ผู้ออกแบบ 27 พ.ย. 2569)

> ✅ ระบบธาตุทำแล้ว v5.40 (ดู CONTROLS.md) · ธนูไม่มีธาตุ ธาตุอยู่ที่ลูกธนู · ✅ นิสัยธนูทำแล้ว v5.41

## ตกลงแล้ว
- อาวุธ **ทุกชิ้น** (ดาบ ขวาน หอก ค้อน มีด แส้ ธนู คทา) มีธาตุได้ 1 ธาตุหรือไม่มี · ธาตุติดที่ตัวอาวุธ (`it.el`) ไม่สร้างอาวุธใหม่ทีละชิ้น
- 6 ธาตุเดียวกับน้อง: 🔥 ไฟ · ⚡ สายฟ้า · 🌱 พืช · 💧 น้ำ · ❄️ น้ำแข็ง · 🪨 หิน
- ชื่อ: "🔥 ดาบอัศวินเพลิง" · ยังมีความหายาก B/R/E/L เหมือนเดิม
- หน้าตา: ใบมีด/หัวอาวุธเปลี่ยนสีตามธาตุ + ประกาย (ส่งภาพให้ดูก่อน)
- ผลตอนโจมตี: 🔥 เผาไหม้ · ⚡ ช็อตกระโดด · 🌱 รากพันขา · 💧 กระแทกถอย · ❄️ หนาวช้า→แข็ง · 🪨 มึน
  - ประชิด 25% ต่อครั้ง · ธนู ลูกพาธาตุ · คทา ทุกนัด (ชาร์จสูงยิ่งแรง)
- ได้มา (เอาทั้งหมด):
  - ดรอปตามอาณาจักร (มอนสเตอร์ถิ่นไหนดรอปธาตุถิ่นนั้น · บอสดรอปธาตุแน่นอน)
  - ช่างตีเหล็กใส่ธาตุ (แร่/หินธาตุ + เหรียญ)
  - สมุดสะสมอาวุธ × ธาตุ (ครบชุดได้รางวัล)
- **มอนสเตอร์แพ้ธาตุ** (เช่น ถิ่นน้ำแข็งโดนไฟ ×1.5)
- คทา: ใช้ ⚡ · ชาร์จ 1–5 · ธาตุตามตัวคทา (คทารากปีศาจ = 🌱)

## ธนูหลายแบบ (ข้อเสนอ · รอผู้ออกแบบยืนยัน)
| ธนู | นิสัย |
|---|---|
| ธนูไม้ | ปกติ |
| ธนูนายพราน | ง้างเร็ว ยิงรัว |
| ธนูทหาร | ปกติ ทนทาน |
| ธนูกระดูก | ทะลุ 2 ตัว |
| ธนูเถาดอกไม้ | ครบ 5 นัด ❤️ คืน (มีแล้ว) |
| ธนูเหยี่ยวทราย | ยิงไกล ลูกเร็ว (มีแล้ว) |
| ธนูอัศวิน | ยิง 3 ดอก กระจายเป็นพัด (ใช้ลูก 1 ดอก) |
| ธนูเสียงระฆัง | โดนแล้วมึนรอบจุด (มีแล้ว) |
| ธนูคริสตัล | ชาร์จเต็ม ลูกเลี้ยวตามเป้า |
