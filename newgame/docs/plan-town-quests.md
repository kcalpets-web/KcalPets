# ร่าง · เควสเมือง 5 อาณาจักรที่เหลือ (รออนุมัติ)

แบบเดียวกับนาวาลี: แต่ละเมืองมีเควสเสริม **9 ข้อ** (👕 ชุด 3 · ⚔️ อาวุธ 3 · 🍲 อาหาร 3) ทำข้อไหนก่อนก็ได้
ชุด 3 ชิ้นเป็น **เซ็ตประจำเมือง** · ทุกชิ้นในเซ็ตมี**ความสามารถเดียวกัน** · ใส่ครบ = ความสามารถนั้นเต็มขั้น (ผู้ออกแบบ: เซ็ตเดียวกัน = ความสามารถเดียวกัน)
อาวุธมีทั้ง **โลหะ ⚡ล่อฟ้า** และ **ไม่ใช่โลหะ** · ส่วนใหญ่ใช้ NPC เดิมของเมือง + NPC ใหม่เมืองละ 1 คน

|---|---|---|

## ทำทีละเมือง (เวอร์ชันละเมือง)
1. ส่งภาพตัวอย่าง: NPC ใหม่ 1 คน · ชุด 3 ชิ้นบนตัวละคร · อาวุธ 3 ชิ้น · อาหาร 3 จาน
2. ผ่านแล้วใส่เกม + เทสต์ + ขึ้นเว็บ
3. ลำดับที่เสนอ: 🌿 ซิลวาเรน → ❄️ ฟรอสต์เฮล์ม → 🏜️ อัสราห์ → 🌋 วัลคาร่า → 💀 เดดการ์

ของใหม่ทั้งหมด: NPC 3 คน (มาลี · อินกา · ซาลิม · วัลคาร่ากับเดดการ์ใช้คนเดิม) · วัตถุดิบใหม่ 1 อย่าง (🌴 อินทผลัม)
