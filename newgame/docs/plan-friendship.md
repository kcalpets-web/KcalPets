# ความสนิท + ยื่นของให้ NPC — 🔨 ทำแล้ว (v4.90 · ยังไม่ขึ้นเว็บ)

ผู้ออกแบบ (24 พ.ย. 2026): ถือของไปให้ NPC ได้ทุกคน · ภาพตัวอย่าง `docs/art/gift-mock.png` ผ่าน · 5❤️ = **ก. ของขวัญพิเศษ**

## ที่ทำในเกม (`D.FRIEND` · main.js `giftNpc/frSpecial/frCard/openFriends`)
1. ถือของ + กด A ที่ NPC (ปุ่มเป็น 🎁 ให้) → NPC รับของชิ้นล่าสุดในมือ
2. 💖 ชอบมาก +3 · 🙂 ธรรมดา +1 · 😣 ไม่ชอบ −1 · วันละ 1 ครั้งต่อคน (วันในเกม)
   ของที่ชอบ: ตามอาณาจักร 2 อย่าง + อีก 1 อย่างต่อคน · ไม่ชอบ: หิน ฟาง ของมอนสเตอร์ เกลือ เมล็ด
3. 3 แต้ม = 1 ❤️ · สูงสุด 5 ❤️ · แสดงในหน้าคุย (ของที่ชอบโชว์เมื่อเคยให้ ❔ = ยังไม่รู้)
4. 3❤️ = เข้าห้องในโรงเตี๊ยมได้ตอนเจ้าของอยู่ (กลางคืน · ไม่ได้ไปบาร์)
5. 5❤️ = ของขวัญพิเศษ: ชุดของอาณาจักรนั้นที่ยังไม่มี + 🪙1500 + 💎5 (ครั้งเดียว)
6. มีเควสของคนนั้นค้างอยู่ → ของในมือกลับเข้ากระเป๋า แล้วคุยส่งเควสได้ตามปกติ
7. ☰ → 📖 สมุด → 💞 เพื่อน: รายชื่อคนที่เคยให้ของ · หัวใจ · 🔑 · 🎁 วันนี้ให้แล้ว

## ยังไม่ครอบคลุม
- เจ้าของร้านในเมืองท่า / มาร์ธา / คนนั่งบาร์ ยังให้ของไม่ได้ (ไม่ใช่ NPC อาณาจักร)
