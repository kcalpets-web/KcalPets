## 2. แก้แล้วคืนนี้ (บน branch)
- **🐕🐈🐋 หน้าต่าง "✨ ได้รับสกิลใหม่!"** ยังถาม "ใส่ไว้ช่องไหน?" ทั้งที่สกิลขี่น้อง/วาฬทำงานเองแล้ว (กดช่องไหนก็ใส่ไม่ได้) → ตอนนี้แสดงวิธีใช้ (เช่น "เดินไปหาน้องแล้วกด ✋ = ขี่") + ปุ่ม "เข้าใจแล้ว"
- คำอธิบายสกิลในหน้าน้อง: เดิมเขียน "กด X ค้าง → วงล้อสกิล" กับทุกสกิล → ตอนนี้เขียนเฉพาะ 🦅 🐻 ⚡ ส่วนที่เหลือบอกวิธีที่ทำงานเอง
- เทสต์ `petq108` เปลี่ยนเป็นขี่ด้วย ✋ · เทสต์ `decks` เลิกตรวจคูน้ำ (เอาออกตั้งแต่ v5.14)

## 4. จุดน่าอัปเดต (จากการเล่น + เทสต์)
1. **ประตูศาลปลาไหล** — ให้ ✋ ขึ้น "เข้า" แม้ยืนในน้ำ (ตอนนี้ขึ้น "ว่ายน้ำ")
2. **แตะต้นไม้แล้วตัดไม่จบ** — เดินไปถึงแล้วไม่ฟัน
3. **ป้าย "บันทึกใหม่"** ชิดขอบซ้ายจนโดนตัด
4. **หน้าน้องว่าง** (ยังไม่มีน้อง) ไม่มีคำแนะนำว่าไปจับที่ไหน
5. **ความคืบหน้า "ภารกิจทั้งหมด 0/328"** เลขใหญ่จนดูท้อ — อาจแบ่งเป็นหมวด
6. **จุดชมพูลอยใกล้ลำแสงเป้าหมาย** (beacon) ดูเหมือนบั๊กภาพ
7. **ม่านหมูป่า (B)** เครื่องช้าบางทีต้องกดค้างสองครั้ง
8. **กองไฟ** ตัดสินใจว่ายืนนิ่งแล้วนั่งพักเองหรือไม่
9. **เศรษฐกิจ** (หลัง v5.32): ได้เหรียญต่อมอนสเตอร์ ต้นเกม ~14 · กลาง ~33 · ท้าย ~52 — ลองเล่นแล้วบอกว่าตึงไปไหม
10. งานค้างเดิม: ไอคอน ⚙️ สีจาง · ฉากจบแสงใหม่ · น้ำตกดินปั้น · เควส NPC เมืองต่างๆ · เรื่องหลังชนะเมฆดำ
