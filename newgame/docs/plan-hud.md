## 🔁 สลับอาวุธ/อุปกรณ์ (26 พ.ย. · ผู้ออกแบบ: ลองหาวิธีแบบ Roblox / Heartopia · ภาพ `docs/art/weapon-switch-options.png`)
ที่หาได้ (แหล่งชุมชน ไม่ใช่เอกสารทางการ):
- Roblox: แถบเครื่องมือล่างจอ · มือถือแสดงแค่ 3 ช่อง · แตะ = ถือ/เก็บ · กระเป๋าเต็มกางขึ้นมา · กดค้างลากเพื่อจัดช่อง · PC กดเลข 1–9
- Heartopia: PC ใช้ปุ่มเลข 1–8 เลือกช่องเครื่องมือ · ปรับปุ่มได้ในตั้งค่า · ยานพาหนะ = กดค้างไอคอนมุมล่างขวาแล้วเลือก (หาข้อมูลมือถือแบบทางการไม่เจอ)
ตัวเลือก:
- R1 แถบ 3 ช่อง + 🎒 ล่างซ้าย (แบบ Roblox) · R2 = เปิด 🎒 แล้วลากของลงช่อง
- H1 ปุ่มหลักโชว์ของที่ถือ · แตะ = ใช้ · กดค้าง = วงล้อ เลื่อนนิ้วแล้วปล่อย (แบบกดค้างเลือกของ Heartopia)
- H2 ไอคอนของที่ถือเหนือปุ่มหลัก · ปัดซ้าย/ขวา = ก่อนหน้า/ถัดไป
- ข้อเสนอ: R1 + H1 (แถบด่วน 3 ช่องที่ผู้เล่นจัดเอง + กดค้างปุ่มหลักเปิดวงล้อเมื่อต้องการของอื่น) · PC = เลข 1–3 + ล้อเมาส์
- ✅ ผู้ออกแบบตอบ "ได้ครับ" กับข้อเสนอ **R1 + H1** (26 พ.ย.) · ยังรอเลือก layout หน้าจอหลัก 1–4
- ✅ ผู้ออกแบบเลือก layout **แบบ 4 มือเดียว** (26 พ.ย.) · ภาพรวม R1 + H1: `docs/art/hud-l4-portrait.png` · `docs/art/hud-l4-landscape.png`
  - บนซ้าย: หัวใจ · 🕘 · แรง · รายการกำลังทำ · บนขวา: ☰ · แผนที่ย่อ
  - ล่างซ้าย: จอย · เหนือจอย (จอตั้ง) / ข้างจอย (จอนอน): แถบด่วน 3 ช่อง + 🎒
  - ล่างขวา: ปุ่มใหญ่ = ของที่ถือ (ฟัน/ตกปลา/คุย ตามสถานการณ์) · วงรอบ 3 ปุ่ม: ✋ ใช้/หยิบ · 🏃 กระโดด · 🛡️ ป้องกัน
  - กดค้างปุ่มใหญ่ = วงล้อของทั้งหมด · ยืนหน้า NPC = ปุ่มใหญ่เป็น 💬 คุย (ฟันย้ายไปวงรอบ)
