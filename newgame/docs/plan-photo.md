# แผน: โหมดถ่ายรูป (แทนวาดภาพ) — ยังไม่ทำ

ผู้ออกแบบ (v4.90): วาดภาพย้ายมาหน้าแรกเมนูแล้ว · ต่อไปจะทำให้เหมือนถ่ายรูป
- ผู้เล่นสลับมุมกล้องได้ · ถ่ายตัวละครตัวเองทำท่าต่างๆ · ถือสิ่งของได้

## คำถามที่รอคำตอบ
1. มุมกล้อง: หน้า · ข้าง · หลัง · เซลฟี่ (แขนยื่น) · มุมสูง — ใช้แบบไหนบ้าง
2. ท่า: โบกมือ · ชูสองนิ้ว · กระโดด · นั่ง · ยกอาวุธ · กอดน้อง — กี่ท่า / ปลดล็อกได้ไหม
3. ถือของ: เลือกจากกระเป๋า (อาหาร ปลา อาวุธ อุปกรณ์) ได้ทุกอย่างไหม
4. น้อง/NPC เข้าเฟรมด้วยไหม
5. รูปเก็บที่ไหน: อัลบั้มในสมุด · บันทึกลงเครื่อง
6. เควสวาดภาพเดิม (สมุด/ภารกิจวาด) เปลี่ยนเป็นถ่ายรูปแทนไหม
