# แผน: เควสหลักแบบใหม่ — รับ/ส่งที่กิลด์เมืองท่า (ผู้ออกแบบ 27 พ.ย. 2569 · กำลังผูกเรื่อง)

> สถานะ: ผู้ออกแบบกำลังเล่าทีละข้อ · ยังไม่ได้ทำในเกม

## หลักการ (ตกลงแล้ว)
- เควสหลักรับ/ส่งที่ 📜 กิลด์เมืองท่า · ตัวเหตุการณ์ (บุกปราสาท ช่วยผู้นำ สู้บอส) ยังเกิดที่อาณาจักรนั้น
- เควสส่วนตัวของชาวบ้าน (ตามหัวใจ) · เควสอาชีพ → ยังรับจากคนนั้นโดยตรง
- ของอาณาจักรขายที่ร้านเมืองท่าหลังชนะบอส (v5.46)

## เส้นเรื่องจากผู้ออกแบบ
1. **หลังเนื้อเรื่องลุงฮาวซิฟ** รับเควสแรกที่กิลด์เมืองท่า มีให้เลือก 2 ทาง:
   1. 🟥 เควสระดับ **SSS** — กำจัดเมฆทมิฬ
   2. ⚓ เควสฟื้นฟูเมืองท่า = ซ่อมร้านต่างๆ แบบที่มีในเกมตอนนี้
   - เลือก SSS ได้ทันที (ไม่ล็อก) · แต่กิลด์ขึ้นคำแนะนำ เช่น "เควสนี้อันตรายมาก แนะนำให้ฟื้นฟูเมืองท่าก่อน"
2. ฟื้นฟูเมืองท่าเสร็จ → กิลด์ส่งไป 🌊 **นาวาลี** ก่อน
   - ถ้าเลือก SSS ตั้งแต่แรก → **ไม่**ถูกส่งไปนาวาลีก่อน · ไปลุยเมฆทมิฬที่ลูมิเนีย**ทันที**
   - สู้ได้จริงตามปกติ (ไม่ใช่ฉากบังคับแพ้) · ในลูมิเนียมีบอสอีกหลายตัวขวางอยู่ก่อนถึงเมฆทมิฬ
   - โอกาสน้อยมากที่ต้นเกมจะผ่านไปถึง **เมฆทมิฬร่างที่ 2** และจบเกมได้ (แต่ทำได้จริง)
   - ✅ **มีในเกมแล้วตั้งแต่ v4.09** (ดันเจี้ยนใต้เมฆทมิฬ `DG`): ประตูเปิดตั้งแต่เริ่ม · **เข้าได้ทางเดียว = บัลลังก์ในท้องพระโรงลูมิเนีย** (v5.46 ผู้ออกแบบ · ตัดหอคอยชั้นบน/แล่นเรือ) · ยังชนะบอสอาณาจักรไม่ครบ 6 = เจอ**ครบทั้ง 6 ตัว**เสมอ (~~ทีละตัว สุ่มลำดับ · v4.44~~ → v5.59 **ทั้ง 6 ตัวพร้อมกัน** ในท้องพระโรงใหญ่) · ครบ 6 แล้ว = เจอเมฆทมิฬเลย · แล้วเมฆทมิฬ → ร่างจริง 🐍 ปีศาจงูยักษ์ · ชนะ = ฉากจบ · แพ้ = ย้อนไปเซฟก่อนเข้า · งานที่เหลือมีแค่ให้กิลด์เป็นคนส่งไป
3. ทำภารกิจนาวาลีเสร็จ → กลับไปส่งเควสที่กิลด์ → เควสใหม่ส่งไปอาณาจักรถัดไป ตามลำดับ:
   🌊 นาวาลี → 🌿 ซิลวาเรน → 🌋 วัลคาร่า → 🏜️ อัสราห์ → ❄️ ฟรอสต์เฮล์ม → 💀 เดดการ์ → 🏰 ลูมิเนีย (จบ)
   - v5.48 สลับ: ฟรอสต์เฮล์มต้องใช้ผลึกไฟจากวัลคาร่า → วัลคาร่าก่อน · ค่าพลังบอสเรียงตามลำดับนี้
   - ทุกอาณาจักร: รับที่กิลด์ → ทำที่อาณาจักร → กลับมาส่งที่กิลด์

## 🌊 นาวาลี (ผู้ออกแบบ 27 พ.ย.) · ✅ ทำแล้ว v5.53
> ✅ v5.53: นีน่าที่ค่าย → เงาดำ → คุ้มกัน 3 ระลอก (❤️ นีน่า · ล้ม = เริ่มที่จุดเงาดำ) → ถ้ำริมทะเลสาบ → ⚙️ หีบลับ 2 + หัวหน้ามนุษย์ปลา 1 → ประตูน้ำ (ปลาไหล 🛡️ ×0.5 · โลหะโดนไฟช็อต) → ชนะ = ปลดปล่อย → รายงานกิลด์ (`S.nv` · ตัวเลข `D.NVQ`)
1. รับเควสนาวาลีที่กิลด์แล้ว 👸 **นีน่า** (ผู้นำนาวาลี · อยู่ใน⛺ ค่ายผู้ลี้ภัยหน้าเมืองท่า · ไม่ได้ถูกขังในปราสาทแล้ว) แอบตามผู้เล่นไปด้วย
2. 🎬 cutscene ระหว่างทาง **ก่อนถึงอาณาจักรนาวาลี**: ผู้เล่นเห็นเงาดำตามหลังมา → จับกุมได้ → เฉลยว่าเป็นนีน่า
3. นีน่าเล่าเรื่องที่เกิดขึ้น: ⚡ **ปลาไหลไฟฟ้ายักษ์** ยึดครองนาวาลี (บอสเดิม)
4. นีน่าเดินทางไปด้วยกัน (เป็นเพื่อนร่วมทาง) จนถึงนาวาลี
   - 🛡️ **ภารกิจคุ้มกัน:** มอนสเตอร์บุกโจมตีระหว่างทาง · ผู้เล่นต้องปกป้องนีน่า **ห้ามให้ตาย**
   - นีน่าไม่สู้ หลบอยู่ข้างหลังผู้เล่น · นีน่าตาย = เริ่มใหม่จากจุดที่เจอเงาดำ (หลังฉากเฉลย)
   - มอนสเตอร์บุก **3 ระลอก** ณ จุดที่กำหนดระหว่างทาง (ระลอกหลังเยอะขึ้น) · แถบ ❤️ ของนีน่าขึ้นจอตลอดทาง
5. ถึงนาวาลี → นีน่าพาไปหา **ชาวบ้านที่ซ่อนตัวอยู่** ใน 🕳️ **ถ้ำริมทะเลสาบ** (ชาวบ้านนาวาลีที่มีอยู่แล้ว: โอเรน มิรา ภราดาโทลล์ ลุชชา กัปตันมาริน)
6. ชาวบ้านขอให้ช่วย **หาฟันเฟืองประตูน้ำ** + เล่า **วิธีกำจัดปลาไหล** (ผู้ออกแบบ: "ตามเหมาะสม" → Claude เสนอ)
   - ⚙️ ฟันเฟือง 3 ชิ้น: 2 ชิ้นในหีบลับของนาวาลี (มีระบบแล้ว) + 1 ชิ้นจาก 🐟 มนุษย์ปลาหัวหน้า (ตัวใหญ่ เฝ้าประตูน้ำ · ดรอปแน่นอน)
   - 🔧 ใส่ฟันเฟืองที่ประตูน้ำ → ระบายน้ำ → น้ำรอบศาลปลาไหลลดลง
   - ⚡ วิธีกำจัด (ชาวบ้านเล่า): น้ำลด = ปลาไหลหนีลงน้ำลึกไม่ได้ · โผล่พ้นน้ำบ่อยขึ้น · DEF ลดลง · และอย่าใช้อาวุธโลหะ (ไฟฟ้าวิ่งเข้าตัว) → ใช้อาวุธไม้/หิน/กระดูก หรือธนู
7. ชนะ ⚡ ปลาไหล → นาวาลีเป็นอิสระ → **กลับไปรายงานที่กิลด์** → เควสถัดไป: 🌿 ซิลวาเรน
   - ✅ ยืนยันแล้ว: นีน่ากับชาวบ้านกลับเข้าเมืองหลวงนาวาลี · ธงเปลี่ยนเป็นสีอาณาจักร · ของนาวาลีขึ้นร้าน (มีแล้ว v5.46) · กิลด์ให้รางวัลเหรียญ + ✨

## 🌿 ซิลวาเรน (ผู้ออกแบบ 27 พ.ย.) · ✅ ทำแล้ว v5.54
> ✅ v5.54: บุกปราสาท (ชั้น 1–2 → ห้องบอส → 🌳 ต้นไม้ปีศาจ) → เปิดกรง ซิลวี่มอบหินบูชาครบ 7 (ที่เก็บเองแล้วคงไว้) → วางบนแท่นให้ตรงรอยสลัก → 🌳 พร = สกิลติดตัวในหน้า ✨ (พัก 6 นาที) → รายงานกิลด์ · จุดอัญมณีเดิม = 💠 หินประจำถิ่น 3 จุด/อาณาจักร งอกใหม่ 20 นาที (ตลาด 75% · ตีบวก +10% · ใส่ธาตุแทนหินธาตุ) · ยังไม่มีสูตรเครื่องประดับ (`S.sv` · ตัวเลข `D.SVQ` `D.LSTN`)
1. รับเควสซิลวาเรนที่กิลด์ (หลังรายงานนาวาลี)
2. 🏰 บุกปราสาทซิลวาเรน ช่วย 🧙 ซิลวี่ที่ถูกขังในกรงข้างบัลลังก์ (ระบบเดิม: เคลียร์ชั้น 1–2 → สู้ 🌳 ต้นไม้ปีศาจ → เปิดกรง)
3. ช่วยสำเร็จ → ซิลวี่ให้ 💎 **หินครบ 7 ก้อน** → นำไปวางที่แท่นบูชา 7 แท่นรอบ 🌳 **ต้นไม้แห่งฤดูกาล** ให้ถูกแท่น (ปริศนาเดิม: แท่นมีรอยสลักรูปทรง) → ผู้เล่นได้ **สกิลใหม่**
   - สกิลที่ได้ = พรเดิม "❤️ หมดแล้วฟื้นเต็ม" เป็น **สกิลติดตัว** (ไม่ต้องกด · คูลดาวน์ 6 นาทีเสร็จก็ทำงานเองทันที) · ขึ้นในหน้า ✨ สกิล
   - จุดซ่อนอัญมณีเดิมทั่ว 7 อาณาจักร → เปลี่ยนเป็น **หินประจำถิ่น** (เหมือนแร่ประจำท้องถิ่น · เก็บได้เรื่อยๆ) · ใช้ได้ 3 ทาง: 🪙 ขายที่ตลาดราคาดี · 🔨 วัตถุดิบตีบวก/คราฟเครื่องประดับ · ✨ ใช้ใส่ธาตุแทนหินธาตุ (ตามธาตุของอาณาจักรนั้น)
4. กลับไปรายงานที่กิลด์ → เควสถัดไป: 🌋 วัลคาร่า

## 🌋 วัลคาร่า (ผู้ออกแบบ 27 พ.ย.) · ✅ ทำแล้ว v5.55
> ✅ v5.55: รับที่กิลด์ → 🦎 ซาลาที่ค่ายผู้ลี้ภัย → ล่า 🦎 กิ้งก่าไฟในวัลคาร่า ได้เกล็ดซาลาแมนเดอร์ 5 แผ่น (ดรอปเฉพาะช่วงนี้ · มีกิ้งก่าไฟโผล่ใกล้ตัว 2 ตัว) → ซาลาเย็บ 🧯 ชุดกันไฟ 3 ชิ้น สวมให้ทันที (☀️×2 · ไม่ติดไหม้ · โลหะไม่ร้อนมือ) · ไม่มีชุด = ประตูปราสาทร้อนเกินเข้า → บุกปราสาท (ชั้น 1–2 → ห้องบอส → 🌋 ปีศาจลาวา) → เปิดกรง อิกนิสมอบ 🔥 ผลึกไฟ (ของสำคัญในกระเป๋า) → รายงานกิลด์ (`S.vk` · ตัวเลข `D.VKQ`)
1. รับเควสวัลคาร่าที่กิลด์ (หลังรายงานซิลวาเรน)
2. 🏰 บุกปราสาทวัลคาร่าช่วย 🔥 อิกนิส (ถูกขังในกรงข้างบัลลังก์ · สู้ 🌋 ปีศาจลาวา)
   - ต้องหา 🧯 **ชุดกันไฟ**: 🦎 ซาลา (อยู่ค่ายผู้ลี้ภัย) ขอให้เก็บ **เกล็ดซาลาแมนเดอร์** (จาก 🦎 กิ้งก่าไฟ ในวัลคาร่า · Claude เสนอ) แล้วเย็บชุดกันไฟให้
3. ช่วยสำเร็จ → อิกนิสให้ 🔥 **ผลึกไฟ** (ใช้ที่ฟรอสต์เฮล์ม) → กลับไปรายงานที่กิลด์ → เควสถัดไป: 🏜️ อัสราห์
