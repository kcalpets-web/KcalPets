# KEALEE — 7 อาณาจักร (ร่าง 14 พ.ย. · แทนแผนบทใน WORLD.md)

**เควสหลักมีอันเดียว: ☁️ กำจัดเมฆทมิฬ ช่วยคีลี**
ฟื้นฟูอาณาจักรได้ 1 แห่ง เมฆทมิฬเหนือเมืองหลวงจะเล็กลง 1/6
ครบ 6 แห่ง เมฆจะหายไปหมด แล้วเข้า 🗼 Light Tower ไปสู้กับร่างจริงของเมฆทมิฬ

**ทุกอาณาจักรมีโครงเหมือนกัน**
- อากาศและชุดที่ต้องใส่
- NPC 4–5 คน ทุกคนมีเควสรอง
- เควสฟื้นฟู 3 ขั้น จบด้วย 🎞️ cutscene ความทรงจำ
- มินิบอส 1 ตัว
- วัตถุดิบท้องถิ่น
- ⛩️ ศาลวาป · หีบลับ · โน้ตปริศนา

**เขตปลอดภัย:** ฟาร์มบนเกาะ · เมืองในแต่ละอาณาจักร · โรงเตี๊ยม
ในเขตนี้ไม่มีมอนสเตอร์ และโจมตีไม่ได้

```
              ❄️ ฟรอสต์เฮล์ม (เหนือ)
   🌊 นาวาลี (ตะวันตก)        💀 เดดการ์ (ตะวันออกเฉียงเหนือ)
              🏰 ลูมิเนีย (กลาง · Light Tower)
   🌿 ซิลวาเรน (ตะวันตกเฉียงใต้)  🏜️ อัสราห์ (ตะวันออก)
              🌋 วัลคาร่า (ใต้)
   เกาะบ้าน + หมู่บ้านเริ่มต้น = ชายฝั่งตะวันตกเฉียงใต้ (ของเดิม)
```
**ขอบโลก**
- เหนือ: หน้าผาน้ำแข็ง
- ตะวันตก: ทะเลลึกที่มีกระแสน้ำวนดันกลับ
- ใต้: เหวลาวา
- ตะวันออก: หน้าผาสูงมีน้ำตก และกำแพงเมืองร้างของเดดการ์

**ลำดับที่แนะนำ**
นาวาลี → ซิลวาเรน → อัสราห์ → ฟรอสต์เฮล์ม → วัลคาร่า → เดดการ์ → ลูมิเนีย
(ไปที่ไหนก่อนก็ได้ แต่มอนสเตอร์จะเก่งขึ้นตามลำดับนี้)

## 🌊 1. นาวาลี — อาณาจักรแห่งน้ำที่ล่มสลาย
**สภาพ:** เมืองท่ากลางทะเลสาบจมน้ำครึ่งเมือง เห็นหลังคาและหอระฆังโผล่พ้นน้ำ
**อากาศ:** ปกติ 🌡️0 · ว่ายและดำน้ำได้

**NPC**
| ชื่อ | เป็นใคร | เควสรอง |
|---|---|---|
| 👴 ตาปุ่น | ชาวประมงแก่ | 🎣 แข่งตกปลา 3 ชนิด · ซ่อมเรือ → สอนสูตร ซุปปลา |
| 🧜 มิรา | นักดำน้ำสาว | 🫧 ดำน้ำเก็บไข่มุก 10 เม็ด · ตามหาตุ๊กตาน้องสาวในซากบ้าน |
| 🔔 ภราดาโทลล์ | คนตีระฆังวัด | ซ่อมหอระฆัง → ⛩️ จุดวาป |
| 🦦 นากน้อยปิ๊ป | สัตว์ติดตาข่าย | ช่วยออกจากตาข่าย → กลายเป็นสัตว์เลี้ยงได้ |
| 🐋 ราชินีวาฬ | วิญญาณผู้พิทักษ์ | ขี่วาฬข้ามทะเลสาบ (กด A ตอนว่ายใกล้วาฬ) |

**ฟื้นฟู**
1. ดำน้ำหาฟันเฟือง 3 ชิ้นของประตูระบายน้ำ
2. ปราบมินิบอสที่ขวางประตูน้ำ
3. หมุนประตูน้ำ น้ำลดลง เมืองโผล่ขึ้นมา

**🎞️ ความทรงจำ:** งานลอยโคมของเมือง จนเมฆทมิฬพาคลื่นยักษ์มาซัดทุกอย่าง

**มินิบอส:** 🦀 ปูยักษ์ "กรามเหล็ก" กระดองแข็ง ต้องตีตอนมันยกก้าม
**วัตถุดิบ:** ปลาหลายชนิด · ไข่มุก · สาหร่าย · หอย · ดอกบัว · มะพร้าว (พุ่มริมหาด)

## 🌿 2. ซิลวาเรน — อาณาจักรป่าไม้ที่เหี่ยวเฉา
**สภาพ:** ป่ายักษ์สีเทา ใบไม้ร่วง กลางป่ามีต้นไม้แม่ที่ใกล้ตาย บางจุดเป็นหนองพิษ
**อากาศ:** ปกติ แต่ในหนองมีพิษ (☠️ ต้องกินยาแก้พิษหรือใส่หน้ากากใบไม้)

**NPC**
| ชื่อ | เป็นใคร | เควสรอง |
|---|---|---|
| 👵 ยายใบตอง | หมอสมุนไพร | 🌸 เก็บดอกไม้ 5 ชนิด → สอนสูตร ชาดอกไม้ |
| 🪵 ช่างไม้บุญมา | ช่างไม้ | 🪓 ตัดไม้ 40 ท่อน สร้างสะพานข้ามลำธาร → สอนสูตรรั้วและเฟอร์นิเจอร์ |
| 🎨 นักเดินทางลีโอ | จิตรกรพเนจร | 🖍️ วาดภาพ 3 วิวที่เขาบอกใบ้ → ได้เฟรมภาพพิเศษ |
| 🦌 กวางขาว | วิญญาณป่า | ตามรอยเท้าไปเจอถ้ำลับ |
| 🍄 คุณเห็ด | คนแคระเห็ด | ทายปริศนา 3 ข้อ → ได้หีบสมบัติ |

**ฟื้นฟู**
1. ล้างพิษ 3 หนองด้วยน้ำศักดิ์สิทธิ์
2. ปลูกเมล็ดแห่งชีวิตที่รากต้นไม้แม่
3. ปกป้องต้นกล้าจากฝูงก็อบลินจนครบ 3 คลื่น

**🎞️ ความทรงจำ:** เด็กๆ ปีนต้นไม้แม่ในวันเก็บเกี่ยว ก่อนรากจะดำเพราะฝนจากเมฆทมิฬ

**มินิบอส:** 🌳 ทรีแอนท์ผีสิง "รากดำ" เรียกรากแทงจากพื้น ต้องยิงธนูใส่ตาที่เรืองแสง
**วัตถุดิบ:** เห็ด · เบอร์รี่ (พุ่ม) · แอปเปิล (ต้น) · ดอกไม้ป่า · น้ำผึ้ง · สมุนไพร

## 🏜️ 3. อัสราห์ — อาณาจักรทะเลทรายที่ถูกปีศาจยึด
**สภาพ:** เมืองทรายสีทองมีพระราชวังโดม ปีศาจแมงป่องตั้งป้อมอยู่ในวัง และมีโอเอซิสที่แห้งไปแล้ว
**อากาศ:** ร้อน 🌡️+2 กลางวัน · หนาว −1 กลางคืน ต้องใส่ชุดบางและกินอาหารเย็น

**NPC**
| ชื่อ | เป็นใคร | เควสรอง |
|---|---|---|
| 🐪 ฮามีร์ | หัวหน้าคาราวาน | 🗺️ คุ้มกันคาราวานข้ามเนินทราย → เปิดร้านในทะเลทราย |
| 👳 ซาร่า | ช่างทอผ้า | 🧵 เก็บไหม/หนัง → สอนสูตร ชุดผ้าบาง เสื้อกล้าม ผ้าคลุมหัว |
| 🌶️ ป้าพริก | แม่ครัว | 🍲 หาพริกทะเลทราย → สอนสูตร ซุปพริกกันหนาว + น้ำแตงเย็น |
| 🧭 นักสำรวจโอ๊ต | นักล่าสมบัติ | ไขแผนที่สมบัติ 3 แผ่น → พีระมิดลับ |
| 👑 เจ้าชายอาซิม | ถูกขังในวัง | ช่วยออกมาเมื่อทำฟื้นฟูขั้นที่ 3 |

**ฟื้นฟู**
1. ขุดหาตาน้ำ 3 จุด เพื่อให้โอเอซิสกลับมา
2. ซ่อมนาฬิกาแดดเพื่อเปิดประตูวัง
3. ปราบมินิบอสในวัง แล้วช่วยเจ้าชาย

**🎞️ ความทรงจำ:** ตลาดกลางคืนที่สว่างด้วยโคมไฟ ก่อนปีศาจจะออกมาจากเงาของเมฆ

**มินิบอส:** 🦂 ราชาแมงป่อง "ซาบัค" ฝังตัวใต้ทราย หางมีพิษ
**วัตถุดิบ:** พริก · แตงโม · อินทผลัม · กระบองเพชร · เกลือ

## ❄️ 4. ฟรอสต์เฮล์ม — อาณาจักรน้ำแข็งที่ถูกผนึก
**สภาพ:** ทั้งเมืองถูกแช่แข็งในก้อนน้ำแข็งยักษ์ มีคนติดอยู่ข้างใน เห็นแสงไฟผ่านน้ำแข็ง
**อากาศ:** หนาว 🌡️−2 ถึง −3 ต้องใส่ชุดกันหนาว อยู่ใกล้กองไฟ/คบเพลิง หรือกินอาหารร้อน

**NPC**
| ชื่อ | เป็นใคร | เควสรอง |
|---|---|---|
| 🧔 บียอร์น | นักล่าหมีที่หลุดผนึกมาได้ | 🏹 ล่าหมีหิมะ 3 ตัว → สอนสูตร เสื้อขนสัตว์ หมวกขนสัตว์ |
| 🔨 กรุนดา | ช่างตีเหล็กคนแคระ | ⛏️ ขุดแร่เงิน 20 ก้อน → อัปเกรดอาวุธ |
| 🐧 ตูตู้ | เพนกวินหลงฝูง | พากลับฝูง → ลื่นไถลบนน้ำแข็งได้ |
| 🕯️ แม่ชีเอลซ่า | ผู้เฝ้าผนึก | ต้องใช้ 🔥 ผลึกไฟจากวัลคาร่า (เชื่อมสองอาณาจักร) |

**ฟื้นฟู**
1. จุดเตาผิงให้ครบ 3 หอคอย
2. นำผลึกไฟมาวางที่แท่น
3. ปราบผู้คุมผนึก น้ำแข็งละลาย

**🎞️ ความทรงจำ:** เด็กๆ ปั้นตุ๊กตาหิมะ แล้วพระราชินีร่ายผนึกเพื่อกันไม่ให้เมฆทมิฬเข้าเมือง

**มินิบอส:** 🐺 จ่าฝูงหมาป่าน้ำแข็ง "ฮาวล์" เรียกฝูงมาช่วย และพ่นลมเย็น
**วัตถุดิบ:** ขนสัตว์ · เนื้อหมี · มินต์หิมะ · เบอร์รี่น้ำแข็ง · แร่เงิน

## 🌋 5. วัลคาร่า — อาณาจักรบนภูเขาไฟที่ร้อนระอุ
**สภาพ:** เมืองช่างตีเหล็กบนไหล่ภูเขาไฟ ลาวาไหลท่วมถนน
**อากาศ:** ร้อน 🌡️+3 ถึง +4 ต้องใส่ชุดกันไฟและกินอาหาร/ยาเย็น

**NPC**
| ชื่อ | เป็นใคร | เควสรอง |
|---|---|---|
| 🧑‍🏭 อาจารย์ไฟร์ | ช่างตีเหล็กตำนาน | 🗡️ หาแร่ลาวา → ตีอาวุธระดับตำนาน |
| 🦎 ซาลา | ซาลาแมนเดอร์พูดได้ | พาข้ามลาวา → สอนสูตร ชุดกันไฟ |
| ⛏️ คนงานเหมือง 3 คน | ติดในเหมือง | ช่วยออกมา → ได้ทางลัดในเหมือง |
| 🔥 ผู้พิทักษ์เปลวไฟ | วิญญาณ | มอบผลึกไฟ (สำหรับฟรอสต์เฮล์ม) |

**ฟื้นฟู**
1. ขุดร่องเปลี่ยนทางลาวา 3 จุด
2. ซ่อมเตาหลอมใหญ่
3. ปราบมินิบอสในปากปล่อง

**🎞️ ความทรงจำ:** วันตีระฆังทองแดงแห่งเมือง จนเมฆทมิฬปลุกภูเขาไฟให้ระเบิด

**มินิบอส:** 🗿 โกเลมลาวา "มักม่า" ตัวแข็ง ต้องรอให้มันเย็นตัว (เป็นสีเทา) แล้วค่อยตี
**วัตถุดิบ:** พริกไฟ · หินภูเขาไฟ · แร่ลาวา · ไข่ซาลาแมนเดอร์

## 💀 6. เดดการ์ — อาณาจักรที่ไร้อากาศ
**สภาพ:** หุบเขาหมอกม่วงมีกำแพงเมืองสูง เป็นที่อยู่ของปีศาจและผีดิบ
**อากาศ:** ไม่มีอากาศให้หายใจ 🫁 มีหลอดลมหายใจ ต้องใส่หน้ากากใบไม้วิเศษหรือดื่มยาหายใจ และพักที่ต้นไม้ฟองอากาศเป็นจุดๆ

**NPC**
| ชื่อ | เป็นใคร | เควสรอง |
|---|---|---|
| 👻 เซอร์การ์ด | อัศวินวิญญาณ | 🛡️ หาชิ้นเกราะเก่า 4 ชิ้น → ได้ชุดเกราะอัศวิน |
| 🧪 หมอดำ | นักเล่นแร่แปรธาตุ | สอนสูตร ยาหายใจ · หน้ากาก |
| 🐦‍⬛ อีกาเฒ่า | นกพูดได้ | พาไปหาโน้ตปริศนา 5 แผ่น (เล่าความลับของเมฆทมิฬ) |
| ⚰️ คนเฝ้าสุสาน | ผู้รอดชีวิตคนสุดท้าย | ฝังวิญญาณที่หลงทาง |

**ฟื้นฟู**
1. จุดตะเกียงวิญญาณ 3 ดวง
2. ทำลายหัวใจหมอก
3. ปราบมินิบอส แล้วได้ 🔑 กุญแจ Light Tower

**🎞️ ความทรงจำ:** ที่มาของเมฆทมิฬ เกิดจากความโลภของพ่อมดราชสำนัก (เฉลยครึ่งหนึ่ง)

**มินิบอส:** 🧟 ราชันผีดิบ "มอร์กัส" ปลุกผีดิบขึ้นมาใหม่ ต้องทำลายโลงศพ 4 ใบรอบตัวก่อน
**วัตถุดิบ:** ดอกไม้ราตรี · กระดูก · ผลึกวิญญาณ

## 🏰 7. ลูมิเนีย — เมืองหลวงกลางแผนที่
**สภาพ:** เมืองหลวงสีขาว Light Tower อยู่ตรงกลาง ทั้งเมืองอยู่ใต้ ☁️ เมฆทมิฬ ที่เล็กลงทุกครั้งที่ฟื้นฟูอาณาจักรได้
**เข้าเมืองได้:** เมื่อเมฆเหลือ 0 และมีกุญแจจากเดดการ์

**NPC**
- 👸 คีลี (ถูกขังบนยอดหอ)
- 🧙 พ่อมดราชสำนักที่กลับตัว (มาช่วยในตอนจบ)
- ทุกคนที่เคยช่วยมาจะเดินทางมาให้กำลังใจ

**ด่านสุดท้าย:** ปีน Light Tower 5 ชั้น แต่ละชั้นใช้ระบบของอาณาจักรหนึ่ง (น้ำ ป่า ทราย น้ำแข็ง ไฟ) แล้วสู้ร่างจริงของเมฆทมิฬ

**🎞️ ตอนจบ:** แสงจากหอส่องไปทั่วแผ่นดิน คีลีกลับบ้าน · หลังจบยังเล่นต่อได้ (เมฆทมิฬฟื้นแบบอ่อนลง)
