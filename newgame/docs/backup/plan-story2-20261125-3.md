# แผน: เนื้อเรื่องหลังกำจัดเมฆทมิฬ (ผู้ออกแบบตอบแล้ว 25 พ.ย. · **เมิร์จแลน = ภาคใหม่** ยังไม่ทำในเกมนี้)

## สิ่งที่มีในเกมแล้ว (ตรวจจากโค้ด)
- ชนะเมฆทมิฬ (`stormWin`) → 🌅 ฉาก New Light บินผ่านเมืองหลวงตอนรุ่งอรุณ (v4.96 · ใน branch) → บทพูด → "แต่… คีลีอยู่ที่ไหนกันนะ?"
- บทที่ 2 (v4.73–4.76): ซ่อมลูมิเนีย 5 จุด → พระราชา → ถูกใส่ร้าย ปลอมตัวเป็นทหาร → ห้องใต้ดิน → แท่นศิลาทอง → ประตูสีดำ → "ประตูแห่งเมิร์จแลนกำลังจะเปิด" (ยังไม่มีต่อ)
- คีลีถูกเงาดำพาไปตั้งแต่ฉากเปิด (ถ้ำหลังน้ำตก) · ยังไม่มีใครรู้ว่าไปไหน

## ข้อเสนอ: บทที่ 3 — ตามหาคีลี สู่เมิร์จแลน
1. **เบาะแสแรก:** ลมจากถ้ำหลังน้ำตกในฉากเปิดคือที่มาของเงาดำ → กลับไปถ้ำหลังน้ำตก (ทำน้ำตกดินปั้นใหม่ ข้อ 6 พอดี) เจอ **ริบบิ้น/ปิ่นผมของคีลี** + รอยแสงสีม่วงแบบเดียวกับประตูดำ
2. **ความทรงจำของคีลี 6 ชิ้น:** ซ่อนอยู่ในแต่ละอาณาจักร (คนที่สนิทครบ 3❤️ จะบอกที่ซ่อน — ต่อยอดระบบความสนิท) · เก็บครบ = กุญแจเปิดประตูเมิร์จแลน
3. **เมิร์จแลน (โลกเวทมนตร์):** แผนที่ใหม่ · เกาะลอยฟ้า · ป่าเวทมนตร์ · เมืองคริสตัล · **เมืองใต้น้ำ** (ผู้ออกแบบ) · มอนสเตอร์ใหม่ · ไม่มีกลางคืน แสงม่วง
4. **ตอนจบบท 3:** เจอคีลีถูกผนึกในคริสตัล · **ตัวร้ายใหม่แห่งเมิร์จแลน** ปรากฏ (บอสใหม่ · ไม่ใช่เมฆทมิฬ) · ชนะ → พาคีลีกลับบ้าน · ฉากหมู่บ้านบนเกาะวาเนญ่าที่ผู้คนกลับมา (ปิดเรื่องฉากเปิด)

## คำตอบผู้ออกแบบ (25 พ.ย.)
1. ทิศทาง "ตามหาคีลี → เมิร์จแลน" ✅ ถูกแล้ว
2. ร่างจริงเมฆทมิฬผู้เล่นรู้จักแล้ว → เมิร์จแลนมี **ตัวร้ายใหม่**
3. เมิร์จแลน: เกาะลอยฟ้า · ป่าเวทมนตร์ · เมืองคริสตัล ✅ + **เมืองใต้น้ำ**
4. ความทรงจำของคีลีต้องสนิทกับ NPC ก่อน ✅ (3❤️ บอกที่ซ่อน)

## คำถามที่เคยถาม (ตอบแล้ว)
1. เห็นด้วยกับทิศทาง "ตามหาคีลี → เมิร์จแลน" ไหม หรือมีเรื่องในใจแล้ว
2. เงาดำที่ลักพาคีลีคือใคร (ร่างจริงของเมฆทมิฬ / ตัวร้ายใหม่ / คนรู้จัก)
3. เมิร์จแลนอยากให้เป็นแบบไหน (เกาะลอยฟ้า · ป่าเวทมนตร์ · เมืองคริสตัล)
4. ความทรงจำของคีลีให้ต้องสนิทกับ NPC ก่อนไหม
