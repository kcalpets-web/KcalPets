# แผน: ความสนิท + ยื่นของให้ NPC (ยังไม่ทำ · รอภาพตัวอย่างผ่าน)

ผู้ออกแบบ (24 พ.ย. 2026): ผู้เล่นถือของได้ → ถือไปให้ NPC ได้ · **ให้ได้ทุกคน** (ผู้อพยพ + เมืองหลวง + เมืองท่า)

## ข้อเสนอ
1. ถือของ (วัตถุดิบ ปลา อาหาร) เดินไปหา NPC → ปุ่ม A เป็น 🎁 → NPC รับของ (ของหายจากมือ)
2. NPC แต่ละคนมีของชอบ: 💖 ชอบมาก +3 · 🙂 ธรรมดา +1 · 😣 ไม่ชอบ −1 (ของเน่า ฯลฯ) · วันละ 1 ครั้ง/คน
3. ความสนิท 5 หัวใจ 🤍→❤️ (แต้ม 0–15 · 3 แต้ม = 1 หัวใจ) แสดงใต้ชื่อในหน้าคุย
4. 3❤️ = เข้าห้องของ NPC ในโรงเตี๊ยมได้ตอนเขาอยู่ (ผู้ออกแบบเคยขอ)
5. เควสหาของ: ถือไปยื่นให้ = ส่งเควสได้
6. 📖 หน้า "เพื่อน" ในสมุด: รายชื่อ NPC ที่รู้จัก · หัวใจ · ของที่ชอบ (เปิดเผยเมื่อเคยให้)

## รอตอบ
- 5❤️ ได้อะไรเพิ่ม (ของขวัญพิเศษ / ส่วนลด / มาช่วยสู้)
