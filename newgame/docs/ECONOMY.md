## 7. 🔨 ตีบวก (เสนอ · ใช้เป็นที่ใช้เงินระยะยาว)
**อาวุธ / โล่ / ธนู** ตีบวกที่ช่างตีเหล็ก +1 ถึง +10
- แต่ละ + เพิ่ม ⚔️/🛡️ +8% ของค่าพื้นฐาน (+10 = +80%)
- ค่าตี: 🪙 + วัตถุดิบตามระดับอาวุธ (ไม้/หิน → ทองแดง → เหล็ก → เงิน → คริสตัล)
- +1 ถึง +5 สำเร็จทุกครั้ง · +6 ขึ้นไปมีโอกาสพลาด
- **พลาด = เสียแค่วัตถุดิบ อาวุธไม่แตก และ + ไม่ลด** (เกมสบายๆ ไม่ทำให้เสียใจ)
- **ใช้อาวุธซ้ำเป็นวัตถุดิบได้** (อาวุธชนิดเดียวกันที่ตกจากมอนสเตอร์ = เพิ่มโอกาสสำเร็จ +15%) ทำให้ของที่ตกซ้ำมีค่า
- ตัวอย่างค่าตี (เสนอ): +1 → 1,000 · +5 → 8,000 · +8 → 25,000 + 20 💎 · +10 → 60,000 + 50 💎

**ชุด / หมวก** เย็บเสริมที่ร้านตัดเสื้อ ★1–★3
- เพิ่มระดับกันหนาว/กันร้อนหรือว่ายน้ำ +1 ต่อดาว หรือเพิ่ม 🛡️ เล็กน้อย
- ใช้ผ้า (หนัง · ขนแกะ · ขนนก) + 🪙
- ชุดเท่ (ไม่มีพลัง) เปลี่ยนสีได้แทน
