# เควสเนื้อเรื่องซิลวาเรน — ร่างทำงาน (เริ่ม 26 พ.ย. 2026)

ผู้ออกแบบ: ทำเควสเนื้อเรื่องให้สอดคล้องกับ NPC แต่ละตัว เริ่มจากซิลวาเรน
สถานะ: **ร่าง · รอผู้ออกแบบเลือก/แก้** (ยังไม่ได้ทำในเกม)

## ข้อมูลที่มีในเกมตอนนี้ (ตรวจจากโค้ด v5.16)
- อาณาจักร: 🌿 ซิลวาเรน "อาณาจักรป่าไม้ที่เหี่ยวเฉา" · หัวใจของเรื่อง = **ต้นไม้แม่** กำลังจะตาย
- ความทรงจำ (ตอนฟื้นฟู): วันเก็บเกี่ยว เด็กๆ ปีนต้นไม้แม่เก็บผลไม้ทองคำ → ฝนดำจากเมฆทมิฬตก 7 วัน 7 คืน → รากต้นไม้แม่ดำลง ใบร่วงหมดป่า
- บอส: 🌳 ต้นไม้ปีศาจ (ดูดพลังต้นไม้แม่) · อยู่บนยอดปราสาทที่ถูกยึด
- มอนสเตอร์: ภูตไม้เหี่ยว · ภูตกิ่งไม้ · ภูตหญ้า · โกเลม: 💚 โกเลมต้นไม้หินทับทิมเขียว
- ฟื้นฟูตอนนี้ = เข้าปราสาทที่ถูกยึด → ช่วยผู้นำในกรง → ชนะบอสที่บัลลังก์
- เควสฟื้นฟูแบบเก่า (ผู้นำ): น้ำศักดิ์สิทธิ์ล้างหนองพิษ (สมุนไพรเรืองแสง 1 · มินต์ 3) → ปกป้องต้นกล้า (ปราบ 8) → ปราบต้นไม้ปีศาจ
- ตอนอาณาจักรถูกยึด: ชาวบ้านอพยพไปพักโรงเตี๊ยมเมืองท่า (ให้แค่เบาะแส ยังไม่ให้เควส) · ผู้นำถูกขังในปราสาท
- หลังฟื้นฟู: ลานเมืองมีรูปปั้นกวาง 🦌 + โคมไฟ · ชาวบ้านกลับบ้าน เควสเปิด
