# New Game — เนื้อเรื่องตอนเปิด + เควสแรก (จากผู้ออกแบบ 12 พ.ย.)

สถานะ: **ร่างจากผู้ออกแบบ** · ส่วน "เสนอ" = Claude เติมให้ต่อกัน รอยืนยัน

## เรื่องย่อ
หลังเหตุการณ์ในถ้ำ ผู้คนทั้งหมู่บ้านหายไป บ้านเมืองถูกทำลาย · Kealee ถูกเงาดำในเมฆควันยักษ์ลักพาตัวไปทางหมู่บ้าน

## Cutscene เปิดเกม (หลัง login ครั้งแรก)
1. **หมู่บ้านสงบสุข** — ผู้คนและสัตว์เลี้ยงใช้ชีวิตอย่างสดใส
2. **เดินในป่า** — NPC เด็กผู้หญิง **Kealee** เดินนำอยู่ข้างหน้า
3. **หน้าผายามอาทิตย์ตก** — Kealee หยุด หันมาพูดกับผู้เล่น (พูดกับจอ): "สวยงามจังเลย"
4. **ฟ้าผ่า** ลงใกล้ๆ Kealee ตกใจ พลัดตกหน้าผา → ผู้เล่นเรียกชื่อแล้วกระโดดตามลงไป
5. **ข้างล่างเป็นแหล่งน้ำ** — รอดทั้งคู่
6. **ถ้ำหลังน้ำตก** — นั่งผิงไฟ · ภาพโฟกัสที่เปลวไฟ · ลมแรงพัดออกมาจากในถ้ำจนไฟดับ · ผู้เล่นเรียก "Kealee"
7. **หน้าต่างใส่ชื่อผู้เล่น**
8. **จอมืดสนิท** — เสียงเรียก "…(ชื่อผู้เล่น)" · "เกิดอะไรขึ้น?" · ผู้เล่น: "ฉันก็ไม่รู้เหมือนกัน"
9. **เสียงคำรามก้องจากในถ้ำ** + ลมแรงกว่าเดิมหลายเท่า · เงาดำบินออกมาพร้อมเมฆควันดำขนาดยักษ์ คว้า Kealee บินหายไปทางหมู่บ้าน · เสียงเรียก "Kealee!" ตามไป
10. **ตัดเข้าเกาะตอนกลางคืน** — ซากบ้านเรือนพังทลาย → เควสเริ่มใช้อุปกรณ์หาวัตถุดิบ ซ่อมแซม และสร้างที่พัก (บ้านต้นไม้)

## เควสเนื้อเรื่อง
| # | เควส | รายละเอียด |
|---|---|---|
| 0 (เสนอ) | ที่พักคืนแรก | ใช้อุปกรณ์หาวัตถุดิบ → สร้างบ้านต้นไม้ → นอน → เช้าวันใหม่ |
| 1 | ใต้ซากเรือ | พบชายชรานอนคว่ำบาดเจ็บใต้ซากเรือ → ช่วยออกมา (เคลียร์ซาก) · **ลุง Howsif** ชาวประมง มอบเบ็ด สอนตกปลา ให้หาปลามาส่ง |
| 2 | ซ่อมเรือ | ลุง Howsif ให้หาวัตถุดิบมาซ่อมเรือที่พัง → (เสนอ) เรือที่ซ่อมเสร็จกลายเป็น **เรือคลังเงิน** |
| 3 | เมืองร้าง | ออกจากเกาะทางเข้าเมืองฝั่งขวา · ผู้คนหายไป บ้านเมืองพัง · **ดาบ 1 เล่มหล่นบนพื้น** ให้หยิบ (สอนใช้ดาบ) · กำจัด **slime** ที่บุกเมืองให้หมดตามกำหนด → เปิดทางไปแผนที่ถัดไป **ในป่า** |

## เมือง (เสนอ: ซ่อมก่อนแล้วร้านเปิด)
ร้านพังทั้งหมด · ซ่อมแต่ละหลังด้วยวัตถุดิบ + เหรียญ (ครั้งเดียว ไม่ซับซ้อน) → ร้านเปิด พร้อมเจ้าของร้านที่รอดกลับมา
ร้าน: อาหารน้อง · ยา · ช่างตีเหล็ก (อาวุธ/ชุดเกราะ) · ช่างอุปกรณ์ทำฟาร์ม/เบ็ด · ตลาด (ขายของ) · กิลด์นักผจญภัย (บอร์ดเควส) · กาชา (ทีหลัง)
