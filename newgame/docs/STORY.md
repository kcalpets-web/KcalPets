# KEALEE — เนื้อเรื่อง (จากผู้ออกแบบ 12 พ.ย.)

สถานะ: **ยืนยันแล้ว 12 พ.ย.** (ผู้ออกแบบตอบครบ)

**ชื่อ:** Kealee = **คีลี** · Howsif = **ลุงฮาวซิฟ** (มาจาก fish เขียนกลับเป็น hsif → h + sif → ใส่ ow ให้อ่านได้)

## ภาพ (12 พ.ย.)
- **คีลี** = วัยรุ่นตอนปลาย/ผู้ใหญ่ตอนต้น (ไม่ใช่เด็ก) · ผมยาวสีน้ำตาล กิ๊บแดง เสื้อขาว กระโปรงยาวสีเขียวน้ำทะเล
- **เงาดำ** = ไม่มีรูปร่าง เป็นแค่เงาเข้มในก้อนเมฆควัน
- ฉากเมฆควันพุ่งออกจากถ้ำ **มีแค่เมฆ** ไม่ต้องเห็นคีลี
- สตอรี่บอร์ด: `docs/art/storyboard-3.png` (9 ฉาก)

## เรื่องย่อ
หลังเหตุการณ์ในถ้ำ ผู้คนทั้งหมู่บ้านหายไป บ้านเมืองถูกทำลาย · Kealee ถูกเงาดำในเมฆควันยักษ์ลักพาตัวไปทางหมู่บ้าน

## Cutscene เปิดเกม (หลัง login ครั้งแรก)
1. **หมู่บ้านสงบสุข** — ผู้คนและสัตว์เลี้ยงใช้ชีวิตอย่างสดใส
2. **เดินในป่า** — NPC เด็กผู้หญิง **Kealee** เดินนำอยู่ข้างหน้า
3. **หน้าผายามอาทิตย์ตก** — คีลีหยุด หันมาพูดกับผู้เล่น (พูดกับจอ): "ดูนั่นสิ!" → ตัดเป็นภาพ**พระอาทิตย์ตกเหนือน้ำ แสงสะท้อนระยิบระยับ**: "สวยงามจังเลย…"
4. **ฟ้าผ่า** ลงใกล้ๆ Kealee ตกใจ พลัดตกหน้าผา → ผู้เล่นเรียกชื่อแล้วกระโดดตามลงไป
5. **ข้างล่างเป็นแหล่งน้ำ** — รอดทั้งคู่
6. **ถ้ำหลังน้ำตก** — นั่งผิงไฟ · คีลี: "ขอบคุณนะ…" · ภาพโฟกัสที่เปลวไฟ · ลมแรงพัดออกมาจากในถ้ำจนไฟดับ · ผู้เล่นเรียก "Kealee"
7. **หน้าต่างใส่ชื่อผู้เล่น**
8. **จอมืดสนิท** — เสียงเรียก "…(ชื่อผู้เล่น)" · "เกิดอะไรขึ้น?" · ผู้เล่น: "ฉันก็ไม่รู้เหมือนกัน"
9. **เสียงคำรามก้องจากในถ้ำ** + ลมแรงกว่าเดิมหลายเท่า · เงาดำบินออกมาพร้อมเมฆควันดำขนาดยักษ์ คว้า Kealee บินหายไปทางหมู่บ้าน · เสียงเรียก "Kealee!" ตามไป
10. **ตัดเข้าเกาะตอนกลางคืน** — ซากบ้านเรือนพังทลาย · ผู้เล่น: "ทุกคนหายไปไหนหมด…" → เควสเริ่มใช้อุปกรณ์หาวัตถุดิบ ซ่อมแซม และสร้างที่พัก (บ้านต้นไม้)

## เควสเนื้อเรื่อง
| # | เควส | รายละเอียด |
|---|---|---|
| 0 | ที่พักคืนแรก | ใช้อุปกรณ์หาวัตถุดิบ → สร้างบ้านต้นไม้ → นอน → เช้าวันใหม่ |
| 1 | ใต้ซากเรือ | พบชายชรานอนคว่ำบาดเจ็บใต้ซากเรือ → ช่วยออกมา (เคลียร์ซาก) · **ลุงฮาวซิฟ** ชาวประมง มอบเบ็ด สอนตกปลา ให้หาปลามาส่ง |
| 2 | ซ่อมเรือ | ลุงฮาวซิฟให้หาวัตถุดิบมาซ่อมเรือที่พัง → เรือที่ซ่อมเสร็จกลายเป็น **เรือคลังเงิน** (เรือของลุง) |
| 3 | เมืองร้าง | ออกจากเกาะทางเข้าเมืองฝั่งขวา · ผู้คนหายไป บ้านเมืองพัง · **ดาบ 1 เล่มหล่นบนพื้น** ให้หยิบ (สอนใช้ดาบ) · กำจัด **slime 5 ตัว + ตัวใหญ่ 1 ตัว (มินิบอส)** → เปิดทางไปแผนที่ถัดไป **ในป่า** |
| 4 | ป่า · น้องตัวแรก | ผู้เล่นถูก **goblin ลอบโจมตี** → **น้องตัวแรกมาช่วย** (ก่อนหน้านี้ผู้เล่นยังไม่มีน้อง) |

## หลังจากนี้
ผู้เล่นไปทำภารกิจตามสถานที่ต่างๆ เพื่อตามหาผู้คนที่หายไปและคีลี

**เมฆดำ** ออกมาเป็นระยะ · เมื่อเมฆดำปกคลุมท้องฟ้า มอนสเตอร์ตามแคมป์ที่ผู้เล่นกำจัดไปแล้ว**ฟื้นคืนชีพ** (กลับไปกำจัดใหม่ได้ — แนว Blood Moon) = ระบบ "เมฆปีศาจ" ใน SPEC ข้อ 4

## เมือง (ยืนยัน: ซ่อมก่อนแล้วร้านเปิด แบบไม่ซับซ้อน)
ร้านพังทั้งหมด · ซ่อมแต่ละหลังด้วยวัตถุดิบ + เหรียญ (ครั้งเดียว ไม่ซับซ้อน) → ร้านเปิด พร้อมเจ้าของร้านที่รอดกลับมา
ร้าน: อาหารน้อง · ยา · ช่างตีเหล็ก (อาวุธ/ชุดเกราะ) · ช่างอุปกรณ์ทำฟาร์ม/เบ็ด · ตลาด (ขายของ) · กิลด์นักผจญภัย (บอร์ดเควส) · กาชา (ทีหลัง)

## บทที่ 2 — ลุงป่วย · ป่าตะวันออก · Sberh (ผู้ออกแบบ 12 พ.ย.)
- ชื่อเกม: **KEALEE** · ตัดข้อจำกัด "มอนสเตอร์ไม่มีขา" ออก (ก็อบลินมีขา)
- **Sberh** (มาจาก herbs) นักปรุงยา ผู้ชายตัวเล็ก อายุราวคีลี · ทูนิกเขียว แว่นกลม ย่าม กิ่งสมุนไพรทัดหู
1. กำจัดราชาสไลม์ → กลับบ้าน → ลุงฮาวซิฟป่วย (นอนห่มผ้าริมท่าเรือ) → บอกว่ามีสมุนไพรเรืองแสงในป่าตะวันออก
2. ประตูตะวันออกของเมือง → ป่า: เก็บสมุนไพรเรืองแสง 3 ต้น (🌾) · มีสไลม์/ภูตหญ้าระหว่างทาง
3. แคมป์ก็อบลิน: ก็อบลิน 4 → หัวหน้าก็อบลิน · มีกรงขัง Sberh
4. **cutscene ช่วยตัวประกัน**: เดินไปที่กรง → Sberh ตะโกน "ระวัง!!" → กล้องค่อยๆ ไปที่ก็อบลินที่ลุกขึ้นมากระโจนใส่ → เงาดำโดดเข้ามาช่วยกำจัด → เลือก หมา/แมว + ตั้งชื่อ → Sberh ขอบคุณ → ชื่อสัตว์เลี้ยงขึ้นจอ (สัตว์เลี้ยงของผู้เล่นที่ซ่อนตัวจนหลงทาง ได้กลิ่นจึงตามมาเจอ)
5. พา Sberh กลับเมือง → ร้านยาพัง → หาวัตถุดิบซ่อม
6. ซ่อมเสร็จ → **cutscene ย้อนอดีต** (สีซีเปีย): Sberh หาสมุนไพร เจอต้นเรืองแสง ดีใจวิ่งเข้าไปเหมือนได้สมบัติ → หันกลับมาเจอก็อบลินทั้งกลุ่มจับตัวไป
7. ได้ยา + วิธีใช้ (แตะไอคอนยา = ดื่ม · กดค้าง = ดื่มอัตโนมัติ) + ยารักษา → เควสนำยาไปให้ลุง → ลุงหาย · จบบทที่ 2
