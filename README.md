# Kcal Pet Dungeon — เว็บแอป (PWA)

ไฟล์ทั้งหมดในโฟลเดอร์นี้คือเกมที่ติดตั้งบนมือถือได้ อัปโหลดทั้งโฟลเดอร์ขึ้นเว็บฟรี (GitHub Pages / Netlify / Cloudflare Pages) ได้เลย

- index.html — ตัวเกม
- manifest.webmanifest — ชื่อแอป ไอคอน สี
- sw.js — ระบบเล่นออฟไลน์ (แก้เกมเมื่อไหร่ ให้เปลี่ยน VERSION ในไฟล์นี้ด้วย)
- icons/ — ไอคอนแอป

ต้องเปิดผ่าน https เท่านั้น ระบบออฟไลน์จึงจะทำงาน (เปิดไฟล์ตรงจากเครื่องจะไม่ทำงาน)
