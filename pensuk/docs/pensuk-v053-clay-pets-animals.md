## น้อง (`buildPet`)
- **rig และจุดยึดเดิม** (`updatePet` ไม่เปลี่ยน: เดิน นอน นั่ง ดม ส่ายหาง):
  - bodyM ศูนย์กลาง y .55 (นอน .38)
  - headG (0, .95, .42)
  - tailG (0, .7, −.5)
  - ขา (±.22, .42, .28 / −.3) • ลูกเจี๊ยบ 2 ขา (±.14, .42, 0)
- **ลำตัว:** ทรงรี (.42, .34, .52) + ท้องสีอ่อน (`sp.belly` หรือสีตัว +30% ขาว)
  - ลายบนหลัง: แต้มเดิม (.34, .2, .38) หรือ **ลายเสือของแมว** = ส่วนโค้งครึ่งวง 3 เส้นที่ z = −.26, 0, .24
  - ขนาดลายตามทรงรีที่ z: f = √(1 − (z/.54)²) + .03
- **ปลอกคอ (ร่าง 2 ขึ้นไป):** อยู่ในชิ้นลำตัว + ป้ายทองห้อยหน้า
- **หัว:** หัว (.37, .34, .35) + แก้มฟูสองข้าง
  - ปาก: ปากยื่นของหมา / จะงอยปากลูกเจี๊ยบ / **จมูกหมูทรงกระบอก + รูจมูก**
  - ตาโตขึ้น (.06 × .075) + ประกาย, แก้มชมพู, ปากยิ้มเล็ก
  - หู 5 แบบ + **สีหูชั้นใน (`earIn`)** สำหรับหูสามเหลี่ยม หูยาว หูกลม
  - แมวมีลายหน้าผาก 3 ขีด
- **มงกุฎ (ร่าง 3):** วงทอง + แฉก 5 แฉกปลายมุก + ทับทิมด้านหน้า
- **ขา:** ขามน + อุ้งเท้าสีอ่อน 15% (ลายถุงเท้าขาวใช้ `legCol` เดิม) • ลูกเจี๊ยบ: ขาส้มเรียว + เท้าแบน
- **หาง:**
  - wag: ท่อน + ปลายสีอ่อน
  - long: 2 ท่อนโค้งตัว S ไปด้านหลัง ปลายใช้สีลาย
  - puff: ก้อนกลม
  - feather: ขนพัด 3 แผ่น
  - curl: วงขด
  - none: ไม่มีหาง
- **ประสิทธิภาพ:** แต่ละส่วน rig เป็น geometry เดียว cache ตาม (ชนิด, skin, ร่าง) + วัสดุ `CLAYP` → 7 draw call (เดิมประมาณ 25)
- **`R3D.thumb('pet', { type, lv, skin }, yaw, size)`:** โหมดใหม่สำหรับภาพตัวอย่างและอบไอคอนภายหลัง
  - สร้างน้องชั่วคราวแล้วให้น้องจริง rebuild ในเฟรมถัดไป

## ไก่และวัวในคอก
- จุดยึดและท่าทาง (sway) เดิม
