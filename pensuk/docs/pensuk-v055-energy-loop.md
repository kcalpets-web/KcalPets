# เป็นสุข v0.55 — ⚡ พลังงาน: ลูปหลัก "ใช้พลังงานทำฟาร์ม → ฟื้นด้วยการขยับหรือพักจอ"

## คำตัดสินผู้ออกแบบ (12 พ.ย. 2026)
- **กลุ่มเป้าหมาย:** คนทำงานนั่งโต๊ะ เล่นบนมือถือเป็นหลัก อยากพักจากงานด้วย
- **ไอเดียผู้ออกแบบ:** "นำกิจกรรมมาสะสมเป็นหลอดพลังงาน ใช้ทำสวน/ฟาร์ม หมดแล้วเลือกวิธีฟื้นจากการออกกำลังกายหรือพักจอ"
- **ตัวเลขที่ยืนยัน:**
  - ขยับ +50
  - พักสายตา/ดื่มน้ำ +15
  - พักจอ 2%/นาที
  - ภารกิจ +30
- **"ให้ฟื้นเถอะครับ ไม่งั้นผู้เล่นจะเบื่อ":** ระหว่างเล่นยังฟื้นเอง 1%/นาที
- **ไม่มีเพดานรายวัน:** มอนสเตอร์จะเป็นตัวเบรคแทน (v0.56)
- **โจมตีมอนสเตอร์ไม่ใช้พลังงาน:** ไล่ด้วยวิธีเดียวกับการฟื้นพลังงาน (v0.56)

## สูตร
- ใช้ระบบความเหนื่อยเดิม (`tiredNow`, `TIRED_MAX` 100) • หลอด = `staminaNow() = 100 − tiredNow()`
- **ระหว่างเล่น:** ฟื้น 1%/นาที (เดิม)
- **ตอนแอปถูกซ่อน:** ฟื้น 2%/นาที
  - ตอนกลับมา (`awayCheck`) เพิ่มส่วนต่าง `AWAY_EXTRA` 1 × นาทีที่หายไป
  - ตัวอย่าง: 25 นาที = +50, 50 นาที = เต็ม
  - เดิม: หายไป ≥ 15 นาที = เต็มทันที
- **การ์ด (`ERG`):**
  - ยืน-นั่ง 5 ครั้ง / ลุกเดินไปดื่มน้ำ 40 ก้าว (ท่าง่าย 28) / บริหารคอ-บ่า: +50
  - พักสายตา 20 วิ (คว่ำมือถือ) / ดื่มน้ำ / หายใจ / พักสายตา 1 นาที (แจ้งเตือนเดิม): +15
  - เดิม: พักทุกแบบ = เต็ม
- **ภารกิจสุขภาพข้อละ +30** (เดิม +20) • ครบ 3 ข้อ +20 (เดิม)
- **คงเดิม:** ยิมจบชุด และชนะมอนสเตอร์ = เต็ม
- **ค่าใช้งาน (ไม่เปลี่ยน):**
  - ถางเล็ก/กลาง/ใหญ่ 1/2/3
  - ขุด ไถ หว่าน เก็บเกี่ยว 1
  - ตกปลา 2
  - เหมือง 2/4/6

## หน้าจอ
- **ชื่อหลอด:** 💪 แรง → ⚡ พลังงาน (ข้อความเกี่ยวกับพลังงานทั้งหมด ไม่รวมชื่อท่า "💪 Shoulder press")
- **แตะหลอด ⚡ ที่มุมขวาบน:** เปิดเมนู "พักกับน้อง" (`tiredSheet`) ได้ทุกเมื่อ
  - พลังงานหมดแล้วเปิดเอง
  - มี 5 การ์ด + "📵 พักจอ ปิดแอปไปทำงาน (เต็มในอีก ~X นาที)" โดย X = ⌈ความเหนื่อย ÷ 2⌉
- **การ์ดพักสายตา 20 วิ:**
  - นับเฉพาะตอนมือถือคว่ำ (deviceorientation |β| > 150°)
  - ถ้าเครื่องไม่ส่งค่า (คอม/ไม่อนุญาต) นับเหมือนจับเวลาปกติ
  - ครบแล้วสั่นและจบเอง
- **การ์ดลุกเดิน:** ใช้ตัวนับก้าวเดียวกับพาสัตว์เดินเล่น
- **การเตือนลุกพักทุก 60 นาที:** ยังสุ่มจาก 5 แบบเดิม (`BRK_CARDS`)

## เควสและแชท (กฎข้อ 4)
- **เควส `ergMenu` "พลังงานหมด เลือกวิธีฟื้น":** แตะหลอด ⚡ → 🪙 100
- **แชท:** ถาม "พลังงาน / แรง / ฟื้น / ⚡" → อธิบายวิธีฟื้นทั้งหมด • ปุ่มแนะนำ "พลังงานหมดทำไง?"

## ทดสอบ (Playwright)
- พลังงาน 0 → งานฟาร์มถูกกั้น + เมนูเปิด (7 ปุ่ม พอดีจอ 390×844)
- ยืน-นั่ง +50, ดื่มน้ำ +15
- หายไป 25/60 นาที: ได้ส่วนเพิ่ม +25/+60 (รวมกับการฟื้นปกติในเวลาจริง = +50/เต็ม)
- แชท / เควส / การเตือนสุ่มเฉพาะ 5 แบบเดิม
- ไม่มี error
