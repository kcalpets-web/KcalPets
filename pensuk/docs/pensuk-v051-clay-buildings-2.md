- footprint, `H`, พื้นที่แตะ, ป้าย และจุดยึดทุกจุดคงเดิม: ประตู, ดุมใบพัดโรงสี (0, 1.9, .42W + .15), โคมเหมือง (.75, 1.12, .38D), ช่องวางสัตว์, รางหญ้า/รังไข่
- ของนิ่งทุกชิ้นรวมเป็น geometry เดียวต่อ (ชนิด, ขนาด, ขั้น) ด้วย `mergeGeo` แล้ว cache ใน `FOLG` (ชุด eco แยกอัตโนมัติ)
- แยกเป็น mesh ต่างหากเฉพาะส่วนที่ขยับหรือเรืองแสง:
  - ใบพัดโรงสี (รวม 4 แขนเป็น 1 mesh)
  - ถ่านเตาตีเหล็ก
  - โคมเหมือง
  - กระจกโรงสี (ใช้ `glassMat`: กลางคืนเรืองส้ม)
  - สัตว์ในคอก (รอช่วง D)
  - เงาอาคารในไซต์ก่อสร้าง
- `tileRows(P, base, rh, len, y0, col, along)` = สูตรกระเบื้องของ `walls()`:
  - hw = base/2, θ = atan2(rh, hw)
  - แถว t อยู่ที่ s = ±hw·t, y = y0 + rh(1 − t) + .05 เอียง ∓θ

## บ้านพัง / ซ่อมตามขั้น
- **ตัวกำหนดขั้น:** k = `S.homes[type]` (จำนวนขั้นที่จ่ายแล้ว) เมื่อ `o.closed` • ซ่อมเสร็จ (`o.closed = 0`) แสดงแบบเต็ม
- **ซากพัง `ruinParts`:**
  - พื้นร้าวแยก 2 ซีก
  - ผนังหักมีขอบแหว่ง (บ้าน) หรือเสาหัก (ศาลา)
  - คานล้มเอียง
  - แผ่นหลังคาฉีกสีหลังคาเดิม (จุดยึดเดิม .1, .55, .1 เอียง .4)
  - กระเบื้องหล่น เศษหิน วัชพืช
- **ครัวป้าบัว (2 ขั้น):**
  - 0 = ซาก
  - 1 = ผนัง + หลังคาตั้งแล้ว เหลือกองไม้กระดาน เศษหิน บันไดพิงผนัง
  - เสร็จ = ลังผัก + กระดานเมนู
- **ศาลาน้องขิง (3 ขั้น):**
  - 0 = ซาก
  - 1 = ยกพื้นแล้ว มีเสาวางรอบนพื้น
  - 2 = เสา + หลังคาแล้ว มีกองไม้และถังสี
  - เสร็จ = ราว ทอง ช่อฟ้า ของตกแต่ง
- เมื่อซ่อมแต่ละขั้น index.html เรียก `markDirty(z)` อยู่แล้ว → ภาพเปลี่ยนทันที

## ไซต์ก่อสร้าง
- **สูตรเดิม:** p = 1 − max(0, end − now) / (objBuildSec(o)·1000)
- **ความสูงเงา:** hh = max(.1, .85·H·p) ที่ y = .15 + hh/2
- **ของในไซต์ (1 mesh):** ลาน เสามุมสูง .9H, นั่งร้านที่ .35H/.75H, ค้ำทแยงด้านหน้า (rz = −atan2(ความกว้าง, .75H)), แผ่นทางเดิน, กองไม้, อิฐ, ป้ายเหลืองคาดดำ
