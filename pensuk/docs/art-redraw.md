## หลักการ (ผู้ออกแบบอนุญาตให้วาดฟาร์มใหม่ทั้งหมด 12 พ.ย. 07:27)

- part = `[geo, x, y, z, sx, sy, sz, ry, rz, tintHex, rx]` (y = จุดกึ่งกลาง) • vertex color → วัสดุร่วม `VCM` (หน้าเดียว) / `VCM2` (สองหน้า)
- **ส่งภาพก่อน/หลังให้ผู้ออกแบบอนุมัติก่อนขึ้นเกมทุกครั้ง**

## ก้อนนูน `blobGeo(key, lo, hi, A, f, sq, cone)` (v0.43)
- SphereGeometry แบบ indexed (ปกติ 24×16, eco 16×10) ดันตาม normal: r' = 1 + A·n
- n = ( sin(3f·n̂x + φ1) + sin(3.7f·n̂y + φ2) + sin(2.9f·n̂z + 2n̂x + φ3) ) / 3
- บีบด้วย sq; cone (สน): y > 0 → x,z ×(1 − .85t), y ×1.25
- สี vertex: mix(lo, hi, smoothstep(−.6, .9, n̂y + .25n)) ± เฉดสุ่มเล็กน้อย (แสงบนฝังในโมเดล อ่านออกแม้ไม่มีเงา)

## ต้นไม้ (v0.43)
- ลำต้น `trunkGeo`: x += b·(y/h)², มะพร้าวมีวงข้อ
- ทางมะพร้าว `frondGeo`: p(u) = (u·len, .45u − 1.2u², 0), w = .38·sin(πu)^.6 หยัก ×1/×.55, พับขอบลง .18w
- ชนิดตามไบโอม: beach/coast → มะพร้าว 70% • mount/peak → สน 70% • อื่น: จามจุรี 55% สน 25% ราชพฤกษ์ 12% มะพร้าว 8%

## ทะเล (v0.44, ใน shader)
- ระนาบ 360×360 ที่ SEA_Y = −0.8 ตามกล้อง (snap 4 หน่วย) • eco 48×48 quads / ปกติ 96×96
- h = .08·sin(.35x + 1.1t) + .06·sin(.5z + .2x − .8t)
- ประกาย: grid 1/2.2 ลอยตาม t, hash ≥ .9, ความสว่าง 6·(N·H)^40 + .45
- alpha = 1 − smoothstep(70, 140, ระยะจาก target)
- roughness 1 (กันแสงสะท้อนขาวทั้งผืน) • ฟองคลื่นเฉพาะด้านที่เป็นทะเลจริง (`seaSides`)

## แสง (v0.44–v0.45)
- hemi .95 (พื้นอุ่น #c9a27e) + sun 2.1 + fill เย็น .45 (ขวากล้อง) + rim อุ่น .75 (หลังฉาก)
- exposure กลางแจ้ง .8 + .2k (k = ความมืด) • ในบ้าน/เหมือง 1.05
- ตัวละคร (อวตาร/NPC/น้อง) ใช้ MeshPhysical sheen ผ่าน `softMode` ใน `mat()`

## พื้น (v0.45, v0.48.2)
- `grassSkin` 1 mesh/โซน (4×4 quad/ช่อง, ข้ามน้ำ) สีพิกัดโลก: n = sin(.45wx + .2wz) + .7 sin(.6wz − .3wx) + .25 sin(1.3(wx + wz)), c = base·(.9 + .12n/1.95)
- ทรายริมทะเล: d = ระยะถึงขอบทะเลจริง, w = 1 − smoothstep(2.6, 4.4, d + .35n), c = mix(หญ้า, #efe2c4, w)

## ธรรมชาติ (v0.48) — `natureGeo(kind, v)`
- หิน: blob เทา #7f7a74→#e0dbd2 (A .18, f 1.3, sq y .62) + มอสเล็ก (.42 ของหิน)
- ใบหญ้า `bladeGeo`: เส้นกลาง (.3u², u, 0), ครึ่งกว้าง .06(1 − u)^.8, กอละ 9 ใบ

## ชุดบ้าน `walls()` (v0.50) — ใช้กับอาคารส่วนใหญ่
- ww = .82W, dd = .82D • ประตู x = −.18ww หน้า (+z) • หน้าต่าง x = +.22ww + หน้าต่างข้าง +x
- หลังคา base = ด้านแคบ + .36, ยาว + .42, rh = .42·base • กระเบื้อง 3 แถว/ด้าน: θ = atan2(rh, base/2), แถว t ∈ {.25,.5,.75} ที่ s = ±hw·t, y = wh + .1 + rh(1 − t) + .05 เอียง ∓θ
- กระจกแยก mesh: `glassMat(NIGHT > .35)` กลางวันฟ้า / กลางคืนเรืองแสงส้มอุ่น
- ตัวบ้าน cache ตาม key สี/ขนาด/ออปชัน (shutters, box, chimney, door)
