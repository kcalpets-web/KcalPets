# เป็นสุข — ทิศทางเกมในมุมเกมสุขภาพ (ร่าง 10–11 พ.ย. 2026)

## คำถามผู้ใช้
"ถ้ามองในมุมเกมสุขภาพ จะแนะนำให้แก้ไขหรือเปลี่ยนแนวทางไปยังไง" → ผู้เล่นเป้าหมาย: **ทุกกลุ่ม**

## หลักใหญ่ (ข้อเสนอ Claude)
- เปลี่ยนเป้าหมายจาก "อยู่ในเกมนาน" → "มาบ่อย สั้น (2–5 นาที) แล้วกลับไปใช้ชีวิตแบบสุขภาพดีขึ้น"
- ตัวชี้วัดความสำเร็จ = พฤติกรรมจริง (พัก/ขยับ/น้ำ/อาหาร/นอน) ไม่ใช่เวลาในเกม
- สุขภาพ = ความคืบหน้าหลัก (เลเวลผู้เล่น/พื้นที่ใหม่มาจากพฤติกรรมสุขภาพเป็นหลัก) • ฟาร์ม = รางวัล/ของขวัญ
- หยุดเพิ่มความลึกของฟาร์ม (ชั้นเหมือง อัปเกรด โรงงานใหม่) จนกว่าแกนสุขภาพจะครบ
- เตือนนอกเกม: Web Push บน iOS 16.4+ เมื่อ "เพิ่มลงหน้าจอหลัก" (ต้องตรวจรายละเอียดก่อนทำ) + Firebase • ระยะยาว: ห่อเป็นแอปอ่าน Apple Health / Google Fit
- หลักสร้างนิสัย: เป้าเล็กมากก่อน • ผูกกับกิจวัตรเดิม • streak ที่ให้อภัย (พักได้) • สรุปรายสัปดาห์ให้เห็นตัวเองดีขึ้น • ระวังรางวัลในเกมกลบแรงจูงใจจริง
- ความปลอดภัย: ไม่เน้นน้ำหนัก/รูปร่าง • อาหาร = เพิ่มของดี ไม่นับแคลอรี/อด • ไม่ใช่คำแนะนำทางการแพทย์ • ปรับตามอายุ/โรคประจำตัว

## ผลของการเลือก "ทุกกลุ่ม"
เกมเดียวต้องเหมาะกับวัยรุ่น คนทำงาน ผู้สูงอายุ → ใช้ "เส้นทางสุขภาพ" ที่ปรับอัตโนมัติจากโปรไฟล์ แทนการทำเกมแยก

| กลุ่ม | เน้น | ปรับอะไร |
|---|---|---|
| วัยเรียน | นอนพอ ลดจอ ขยับ | เตือนเวลานอน เป้าจอ/วัน ไม่ใช้น้ำหนัก |
| คนทำงานหน้าจอ | พักตา ลุกจากโต๊ะ น้ำ | รอบวันทำงาน เตือนตามชั่วโมงทำงาน |
| ผู้สูงอายุ | เดิน ทรงตัว น้ำ ยา/นัด (อนาคต) | ตัวหนังสือ/ปุ่มใหญ่ เกมช้าลง (มีแล้ว: ปลาช้า 30%) |
| ทั่วไป | 3 เสา ออกกำลัง อาหาร นอน | ค่าเริ่มต้น |

- หน้าเริ่มเกมถามเพิ่ม: ช่วงวัย (มีแล้ว), ลักษณะวันปกติ (เรียน/ทำงานหน้าจอ/ทำงานใช้แรง/อยู่บ้าน/เกษียณ), เป้าหมายที่อยากดีขึ้น 1–2 ข้อ
- เป้าเริ่มเล็ก แล้วเพิ่มตามที่ทำได้จริง (ไม่ใช่ตามค่ามาตรฐานทันที)
- ตั้งค่าการเข้าถึง: ขนาดตัวอักษร, ลดแอนิเมชัน, โหมดง่าย (มินิเกม)
