# เป็นสุข v0.53.1 — อบไอคอน atlas2 ใหม่จากโมเดลดินปั้น (ปิดแผนวาดฟาร์มใหม่)

## คำตัดสินผู้ออกแบบ
- "ทำตามสะดวก" → ทำเฉพาะการอบใหม่
- ยังไม่เปลี่ยนอีโมจิน้องใน UI เป็นไอคอน 3D และยังไม่เพิ่มไอคอนป้านวล/ลุงปลา (เป็นงาน UI แยก ถ้าต้องการ)

## ปัญหาที่พบ
- `tools/bake_thumbs.js` ใน repo มี LIST เขียนมือ 43 รายการ ลำดับไม่ตรง `ICO2` (53 รายการ)
  - ถ้ารันตามที่เป็นอยู่ ไอคอนตั้งแต่ช่อง 31 จะเลื่อนผิดช่องทั้งหมด
- สคริปต์ชี้ไปที่ `/usr/bin/google-chrome` ซึ่งไม่มีในเครื่องนี้
- URL ของ atlas ติด `?v=0.45.3` → ผู้เล่นจะเห็นไฟล์เก่าจาก cache

## สิ่งที่ทำ
- **สคริปต์อ่าน `ICO2` จากหน้าเกมตอนรัน** แล้วแปลงคำนำหน้าเป็นชนิดไอคอน:
  - `b_` → build
  - `f_` → furn
  - `p_` → path
  - `n_` → npc
  - `m_` → item
  - `bridge` → bridge
- ใช้ Chromium ของ Playwright
- พิมพ์ error ในหน้าเว็บออกมาด้วย
- **อบใหม่ 53 ไอคอน:** 1024×896 (8×7 ช่อง × 128 px), webp คุณภาพ .9
  - ใช้โมเดล v0.49 (ของในฟาร์ม), v0.50–v0.51 (อาคาร), v0.52 (NPC), v0.53 (ไก่/วัวในไอคอนคอก)
- **cache-bust:** `.ico.i2` และ `bigIco` ใช้ `atlas2.webp?v=0.53.1`
  - **ต้องอัปเลขนี้ทุกครั้งที่อบใหม่**
- ส่งภาพเทียบเก่า/ใหม่ทีละช่องให้ผู้ออกแบบแล้ว

## วิธีเพิ่มไอคอนใหม่
1. เพิ่มชื่อท้าย `ICO2` (ถ้าเกิน 56 ช่อง ต้องแก้ background-size ใน `.ico.i2`)
2. ต้องมีโมเดลใน `R3D.thumb` ตามชนิด
3. รัน server แล้วรัน `NODE_PATH=$(npm root -g) node pensuk/tools/bake_thumbs.js`
4. อัป `?v=` ของ atlas2
