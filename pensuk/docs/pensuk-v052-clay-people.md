# เป็นสุข v0.52 — งานภาพช่วง D1: คน (ผู้เล่น ชาวเมือง คนในร้าน ลุงปลา)

## คำตัดสินผู้ออกแบบ (12 พ.ย. 2026)
- สัดส่วน: "ปรับแต่งตามที่ถนัดได้เลย" → หัวโตขึ้น 10% (×1.1) ความสูงรวมเพิ่มประมาณ .05 หน่วย
- แบ่งรอบ: "ตัดสินใจตามเหมาะสม" → D1 คน (v0.52) → ส่งภาพ → D2 น้อง + สัตว์ฟาร์ม (v0.53)

## สิ่งที่คงเดิม
- ฟิลด์ look ทุกตัวและสีประจำตัวของ NPC ทุกคน
- ตำแหน่งจุดหมุน:
  - ขา (±.13, .62, 0)
  - แขน (±.33, 1.12, 0)
  - หัว y 1.5 (เดิม 1.48 ยกขึ้นเพราะหัวใหญ่ขึ้น)
  - ทั้งตัว ×.95
- ท่าเดิน โบกมือ เชียร์ สควอต และท่าทำงานในร้านใช้โค้ดเดิม (`userData.parts`)

## รูปทรงใหม่
- **ลำตัว:** LatheGeometry ทรงถั่ว r(y) ผ่านจุด (.2, 0) (.265, .08) (.27, .3) (.25, .5) (.2, .6) (.08, .64) บีบความลึก ×.72
  - ขอบชายเสื้อ (torus สีเข้ม ×.82), คอ, ปกเสื้อ, กระดุม 2 เม็ด (ยกเว้นชุดกีฬา/ไทย)
- **แขน:** หัวไหล่ + แขนเสื้อ capsule + ขอบแขน + มือกลม + นิ้วโป้ง
- **ขา:** กางเกง capsule (ชุดกีฬา: ขาสั้น + หน้าแข้ง) + รองเท้ามน + พื้นรองเท้าสีเข้ม (+ แถบรองเท้าวิ่ง)
- **หน้า:** ตา + ประกาย, คิ้ว (สีผม ×.85), จมูก, แก้มชมพู, ปากยิ้มเป็นส่วนโค้ง torus ครึ่งวง, หู
- **ผม 7 แบบ:**
  - blob ผิวขรุขระ (A .06, f 3) ไล่สีจาก ×.72 ถึงสีผมจริง
  - มีหน้าม้า 3 ก้อน ยกเว้นทรงตั้ง
  - บ็อบ: ก้อนผมใหญ่ขึ้นแต่ไม่บังหน้า
  - มวย/หางม้า: มีหนังยางสีส้ม
- **หมวก 6 แบบ ชุด 3 แบบ ของประกอบ:** ผ้ากันเปื้อน (+กระเป๋า + สาย) เสื้อกั๊ก แว่น ลูกโป่ง (มีไฮไลต์) เลื่อย นกหวีด
- ทุกส่วนอยู่ในพิกัดเดิม
